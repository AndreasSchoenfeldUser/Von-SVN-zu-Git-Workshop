Sechs Arten von Branches, zwei davon dauerhaft

BranchZweckEntsteht ausWird gemergt inTag
mainProduktiver Stand––Auslieferung, Hotfix
developStand der Entwicklungmain (einmalig)–Entwicklungsrelease
feature/*Neue Funktiondevelopdevelop–
bugfix/*Fehler im Entwicklungsstanddevelopdevelop–
release/*Release festigendevelopmain und developAuslieferung
hotfix/*Dringender Fix in Produktionmainmain und developHotfix

main und develop bestehen dauerhaft. Alle anderen Branches leben nur so lange wie ihre Aufgabe und werden per Merge Request zurückgeführt.

Von SVN zu Git · Tag 2

Die Rückführung von Release- und Hotfix-Branches nach develop ist eine Empfehlung: Ohne sie fehlt die Korrektur im nächsten Release. Wo ein Release-Branch offen ist, wird ein Hotfix stattdessen dorthin zurückgeführt.
