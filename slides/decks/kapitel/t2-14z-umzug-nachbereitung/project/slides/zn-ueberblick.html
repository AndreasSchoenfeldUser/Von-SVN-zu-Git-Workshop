Theorie

Zusatzmodul · Nachbereitung des Umzugs

Drei Aufgaben nach dem Umzug

GIT LFS

Große Dateien

Bilder, Videos und Bibliotheken liegen auf dem LFS-Server. Im Repository bleibt nur ein kleiner Verweis.

SUBMODULE

Gemeinsame Bibliotheken

Ein anderes Repository wird in einer festen Version eingebunden. Das ersetzt svn:externals.

SCHNEIDEN

Zu große Repositories

Teilprojekte samt ihrer Historie in eigene Repositories auslagern.

LFS-Migration und Schneiden schreiben die Historie um. Beides gehört direkt hinter die Migration, bevor das Team das Repository klont.

Von SVN zu Git · Tag 2

Nach dem Umschreiben haben alle Commits neue IDs. Wer vorher geklont hat, muss neu klonen. Deshalb diese Schritte im Probelauf üben und am Stichtag direkt nach der Migration ausführen.
