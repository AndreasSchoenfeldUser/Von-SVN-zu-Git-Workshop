Modul 01 · Auftakt

Zentral und verteilt: zwei Arten, Historie zu organisieren

SO KENNEN SIE ES

Zentrale Versionsverwaltung

  • Die Historie liegt auf einem Server
  • Viele Aktionen brauchen eine Verbindung
  • Jeder Commit wird sofort für alle sichtbar

SO ARBEITET GIT

Verteilte Versionsverwaltung

  • Jede Kopie enthält die vollständige Historie
  • Fast alles geschieht lokal und schnell
  • Veröffentlichen ist ein eigener Schritt

Von SVN zu Git · Tag 1

Kein Werturteil: Beide Modelle funktionieren. Entscheidend ist, dass sich daraus andere Arbeitsgewohnheiten ergeben. Fragen Sie die Gruppe, wo sie heute auf den Server warten oder Änderungen bewusst zurückhalten.
