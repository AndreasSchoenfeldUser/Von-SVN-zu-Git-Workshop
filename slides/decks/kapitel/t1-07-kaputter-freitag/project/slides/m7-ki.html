Modul 07 · Der kaputte Freitag

Mit KI vertiefen

VERSTEHEN

Erkläre, wie git bisect funktioniert und wann es schneller zum fehlerhaften Commit führt als git log und git blame. Rechne vor, wie viele Schritte bei 500 Commits nötig sind.

ÜBEN

Simuliere ein Repository mit zehn Commits, in dem sich ein Fehler versteckt. Ich frage dich nach Ausgaben von git log, git show und git blame, bis ich den verantwortlichen Commit gefunden habe.

ÜBERTRAGEN

Wie kombiniere ich git bisect mit einem automatisierten Test wie mvn test? Zeige den Ablauf mit git bisect run und erkläre die Bedeutung der Exit-Codes.

Für Claude und ChatGPT. Antworten mit den Referenzen abgleichen, keinen vertraulichen Code eingeben.
