Konflikte besser lesen, Lösungen wiederverwenden

Zwei Einstellungen, die jedes Team setzen sollte. Sie ergänzen das Vorgehen aus Modul 09.

$ git config --global merge.conflictStyle zdiff3
$ git config --global rerere.enabled true
$ git merge suche/trefferzahl
Recorded preimage for '…/application.yml'
# Inhalt von application.yml:
<<<<<<< HEAD
    max-ergebnisse: 30
||||||| 066b886
    max-ergebnisse: 20
=======
    max-ergebnisse: 25
>>>>>>> suche/trefferzahl

zdiff3

Zeigt zusätzlich den Stand der Merge-Basis. So ist erkennbar, wer was geändert hat.

rerere

Merkt sich gelöste Konflikte und löst denselben Konflikt beim nächsten Mal selbst.

git checkout --theirs

Übernimmt für eine einzelne Datei vollständig eine Seite.

Von SVN zu Git · Tag 2

Ohne zdiff3 sieht man nur 30 gegen 25. Mit der Basis 20 wird klar: Beide Seiten haben die Trefferzahl erhöht, das Team muss sich auf einen Wert einigen. rerere steht für „reuse recorded resolution“. Es hilft, wenn derselbe Konflikt mehrfach auftritt, etwa bei einem wiederholten Rebase. Die gelöste Datei muss trotzdem mit git add vorgemerkt werden.
