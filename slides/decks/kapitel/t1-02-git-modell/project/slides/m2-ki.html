Modul 02 · Das Git-Modell

Mit KI vertiefen

VERSTEHEN

Erkläre Working Directory, Staging Area und lokales Repository mit einer Analogie außerhalb der Softwareentwicklung. Zeige dann nach jedem Schritt (Ändern, git add, git commit), welchen Stand der Datei die drei Bereiche jeweils enthalten.

ÜBEN

Gib mir fünf Ausgaben von git status --short und lass mich jeweils sagen, in welchem Bereich sich jede Datei befindet. Löse erst nach meiner Antwort auf.

HINTERGRUND

Warum verwendet Git Hashes statt fortlaufender Revisionsnummern? Erkläre, woraus ein Commit-Hash berechnet wird und was das für die Unveränderlichkeit der Historie bedeutet. Unterscheide dabei Integrität (Hash) und Herkunft (Signatur).

Für Claude und ChatGPT. Antworten mit den Referenzen abgleichen, keinen vertraulichen Code eingeben.
