Modul 04 · In kleinen Schritten arbeiten

Commits als Arbeitsprotokoll

EMPFEHLUNG

So gelingt es

  • Ein Commit enthält genau eine Absicht
  • Häufig committen, sobald ein Schritt fertig ist
  • Vor jedem Commit prüfen, was vorgemerkt ist
  • Generierte Dateien vom Repository fernhalten

STOLPERFALLEN

Das vermeiden Sie

  • Der „Feierabend-Commit“ mit allem, was gerade offen ist
  • Mehrere Themen in einem Commit
  • Beschreibungen wie „Änderungen“ oder „fix“
  • Build-Ergebnisse und Logdateien im Repository

Von SVN zu Git · Tag 1

In SVN war der Commit oft der Moment der Veröffentlichung und deshalb groß und selten. In Git darf er klein sein. Das macht spätere Fehlersuche und Reviews deutlich leichter.
