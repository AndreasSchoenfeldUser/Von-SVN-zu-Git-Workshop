Autoren ermitteln

Schritt 1: alle SVN-Benutzer aus der Historie in eine Datei authors.txt schreiben.

$ svn checkout https://svn.example.com/reiseportal
$ cd reiseportal
$ svn log -q > svn.log
$ cat svn.log | awk -F '|' '/^r/ {
>     sub("^ ", "", $2); sub(" $", "", $2)
>     print $2" = "$2" <"$2">"
>   }' | sort -u > authors.txt
 
$ cat authors.txt
mmuster = mmuster <mmuster>
tschulz = tschulz <tschulz>

svn log -q

Listet alle Revisionen mit Autor und Datum, ohne Commit-Nachrichten.

awk

Schneidet den Benutzernamen aus der zweiten Spalte und baut daraus eine Zeile im Format der Autorenzuordnung.

sort -u

Jeder SVN-Benutzer erscheint genau einmal.

Von SVN zu Git · Tag 2

svn log arbeitet auch direkt mit der URL des Repositorys, dann ist kein Checkout nötig. Wichtig ist, dass die gesamte Historie erfasst wird, nicht nur der Teil einer Arbeitskopie.
