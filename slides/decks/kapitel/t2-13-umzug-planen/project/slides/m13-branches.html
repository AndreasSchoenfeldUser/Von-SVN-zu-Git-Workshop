SVN-Branches als Git-Branches anlegen

Schritt 5: Für jeden SVN-Branch entsteht ein lokaler Git-Branch.

$ git for-each-ref | grep -v tags \
>   | grep -v @ | grep -v %20 \
>   | grep -v trunk | grep -v main \
>   | cut -d / -f 4- \
>   | while read ref; do
>       git branch "$ref" "refs/remotes/svn/$ref"
>     done
$ git branch
* main
  merkliste
$ git push --all

grep -v

Lässt Tags, Hilfsstände mit @, Namen mit Leerzeichen (%20), trunk und main aus.

trunk

Wird nicht kopiert: Der lokale Branch main ist beim Klonen bereits aus svn/trunk entstanden.

git push --all

Teilt alle lokalen Branches in GitLab.

Von SVN zu Git · Tag 2

Branches mit Leerzeichen im Namen werden von Hand mit einem gültigen Git-Namen angelegt. Vorher mit dem Team klären, welche alten Branches überhaupt noch gebraucht werden.
