SVN-Tags in Git-Tags umwandeln

Schritt 4: Aus den Tag-Verzeichnissen von SVN werden echte Git-Tags.

$ git for-each-ref refs/remotes/svn/tags \
>   | grep -v @ | cut -d / -f 5- \
>   | while read ref; do
>       git tag "$ref" "refs/remotes/svn/tags/$ref"
>     done
 
$ git tag
1.0
1.1
$ git remote add origin <GitLab-URL>
$ git push --tags

Ausgangslage

In SVN sind Tags Kopien in einem Verzeichnis. git svn legt sie deshalb als Branches unter svn/tags/ ab.

grep -v @

Lässt Hilfsstände wie 1.0@1234 aus, die git svn für gelöschte oder neu angelegte Tags anlegt.

cut -d / -f 5-

Behält nur den Namen des Tags.

Von SVN zu Git · Tag 2

Die Tags zeigen danach auf genau den Commit, den der SVN-Tag markiert hat. Wurde in SVN nach dem Taggen noch im Tag-Verzeichnis committet, ist das an dieser Stelle zu prüfen.
