Schrittweise migrieren

Schritt 3: die Historie mit git svn übernehmen, bei großen Repositories in Etappen.

$ git svn clone https://svn.example.com/reiseportal \
>   --authors-file=authors.txt --prefix=svn/ \
>   --trunk=trunk/ --branches=branches/ \
>   --tags=tags/ -r 1:2000 reiseportal-git
$ cd reiseportal-git
$ git svn fetch -r 2001:4000
$ git svn fetch # restliche Revisionen bis HEAD
 
$ git branch -r
  svn/merkliste
  svn/tags/1.0
  svn/trunk

--trunk, --branches, --tags

Wo Hauptlinie, Branches und Tags im SVN-Repository liegen.

--prefix=svn/

Die SVN-Stände erscheinen in Git als svn/trunk, svn/<Branch> und svn/tags/<Tag>.

-r von:bis

Übernimmt die Historie in Etappen. Jedes git svn fetch setzt dort fort.

Von SVN zu Git · Tag 2

Große Repositories mit vielen tausend Revisionen brauchen für den Klon Stunden. In Etappen lässt sich die Migration unterbrechen und fortsetzen, und erste Ergebnisse lassen sich früh prüfen.
