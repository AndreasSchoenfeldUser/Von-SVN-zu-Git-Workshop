Modul 06 · Ein Branch pro Aufgabe

Neue Funktion auf eigenem Branch

$ git switch -c feature/merkliste
Switched to a new branch 'feature/merkliste'
$ git add src/main/java/de/reiseportal/Merkliste.java
$ git commit -m "Merkliste für Reiseangebote ergänzen"
$ git switch main
$ git merge feature/merkliste
Updating 9a7b6c5..a1b2c3d
Fast-forward
$ git branch -d feature/merkliste
$ git log --oneline --graph --all

git switch -c

Legt einen Branch an und wechselt sofort dorthin.

git merge

Holt die Arbeit eines Branches in den aktuellen Branch.

git branch -d

Entfernt den Namen nach erledigter Aufgabe. Die Commits bleiben.
