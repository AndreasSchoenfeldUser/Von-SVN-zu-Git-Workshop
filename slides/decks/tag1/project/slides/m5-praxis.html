Ein Experiment mit der Reisesuche

$ git stash # unfertige Arbeit parken
Saved working directory and index state WIP on main
$ git switch --detach 3f2a9c1 # alten Stand ansehen
$ git switch main
$ git stash pop # Arbeit zurückholen
 
# Ein Commit hat sich als falsch erwiesen:
$ git revert 8c1d2e4
[main 4b5c6d7] Revert "Stornofrist auf 30 Tage erhöhen"
$ git log --oneline -3

git stash

Parkt Änderungen, damit Sie kurz etwas anderes erledigen können.

git switch --detach

Einen früheren Stand ansehen, ohne etwas zu verändern.

git revert

Hebt einen Commit nachvollziehbar mit einem neuen Commit auf.

Von SVN zu Git · Tag 1

Hinweis: Im Detached-HEAD-Zustand nicht arbeiten, nur ansehen. Mit git switch main geht es zurück.
