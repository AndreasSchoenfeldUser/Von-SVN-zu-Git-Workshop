Was nicht ins Repository gehört

# Datei .gitignore im Projektverzeichnis
# Build-Ergebnisse
build/
*.log
# Lokale Einstellungen
.vscode/
*.bak
 
$ git add .gitignore
$ git commit -m "Build-Ausgaben ignorieren"

.gitignore

Eine Datei im Repository. Alle im Team teilen dieselben Regeln.

build/

Ein Schrägstrich am Ende steht für ein ganzes Verzeichnis.

*.log

Muster gelten für alle passenden Dateien im Projekt.

Von SVN zu Git · Tag 1

Wichtig: .gitignore wirkt nur auf Dateien, die Git noch nicht verwaltet. Bereits erfasste Dateien müssen einmal mit git rm --cached entfernt werden.
