Eine gute Commit Message beantwortet das Warum

GUT

Füllmenge Apfelsaft auf 750 ml reduzieren

Ab KW 3 werden 0,75-l-Flaschen abgefüllt.
Rezept für Linie 2 angepasst; Linie 1 folgt nach dem Umbau.

REGELN

Aufbau einer Commit Message

  • Betreff mit höchstens 50 Zeichen
  • Betreff im Imperativ: „anpassen“, „ergänzen“
  • Leerzeile, dann das Warum
  • Kein „fix“, „wip“ oder „Änderungen“

Von SVN zu Git · Tag 1

Die Betreffzeile erscheint in allen Übersichten. Das Warum steht im Text darunter, das Was zeigt der Diff ohnehin.
