Modul 04 · In kleinen Schritten arbeiten

Aufräumen in kleinen Schritten

  1. Wechseln Sie zum vorbereiteten Stand modul04. Er enthält drei unabhängige Änderungen und mehrere Logdateien.
  2. Verschaffen Sie sich einen Überblick über alle Änderungen.
  3. Sorgen Sie dafür, dass Logdateien künftig ignoriert werden.
  4. Erstellen Sie drei getrennte Commits mit aussagekräftigen Beschreibungen.
  5. Vergleichen Sie Ihre Historie mit der Ihres Sitznachbarn.

ZEIT

30 Minuten

ARBEITSFORM

Einzelarbeit, Vergleich zu zweit

ERGEBNIS

Saubere Historie mit drei Commits und einer .gitignore-Datei.

Von SVN zu Git · Tag 1

Der Stand modul04 liegt als Branch in der Schulungsumgebung bereit. Wechsel mit git switch modul04; das Konzept dahinter folgt in Modul 06.
