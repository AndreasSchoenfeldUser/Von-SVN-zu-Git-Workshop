Modul 03 · Arbeiten und festhalten

Prüfen, bevor festgehalten wird

$ git diff
--- a/src/main/resources/application.yml
+++ b/src/main/resources/application.yml
@@ -3 +3 @@
-    max-ergebnisse: 50
+    max-ergebnisse: 20
 
$ git add src/main/resources/application.yml
$ git diff --staged # zeigt den nächsten Commit
$ git commit -m "Trefferzahl der Reisesuche begrenzen"
$ git show --stat

git diff

Änderungen, die noch nicht vorgemerkt sind.

git diff --staged

Genau das, was im nächsten Commit landen wird.

git show

Inhalt und Beschreibung eines festgehaltenen Commits.

Von SVN zu Git · Tag 1

Gewohnheit etablieren: Vor jedem Commit einmal diff --staged. Das verhindert die meisten versehentlichen Commits.
