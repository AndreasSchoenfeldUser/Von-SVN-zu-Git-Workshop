Modul 04 · In kleinen Schritten arbeiten

Eine Datei, zwei Absichten: gezielt vormerken

$ git add -p config/anlage.yaml
@@ -12 +12 @@
-temperatur_max: 80
+temperatur_max: 85
Stage this hunk [y,n,q,a,d,s,e,?]? y
@@ -40 +40 @@
-# Wartungsintervall in Stunden
+# Wartungsintervall in Betriebsstunden
Stage this hunk [y,n,q,a,d,s,e,?]? n
 
$ git commit -m "Temperaturgrenze auf 85 °C anheben"

git add -p

Geht die Änderungen abschnittsweise durch und fragt jeweils nach.

y / n

Abschnitt vormerken oder für einen späteren Commit liegen lassen.

Ergebnis

Zwei saubere Commits statt eines vermischten.
