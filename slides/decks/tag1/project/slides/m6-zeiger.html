Von SVN zu Git · Tag 1

In SVN war ein Branch eine Verzeichniskopie auf dem Server und deshalb eher selten. In Git ist er ein Name von wenigen Bytes. Daraus folgt die Arbeitsweise: ein Branch pro Aufgabe.
