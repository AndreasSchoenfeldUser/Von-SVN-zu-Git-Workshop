Modul 02 · Das Git-Modell

Wo steht meine Änderung gerade?

$ git status
On branch main
Changes not staged for commit:
        modified:   rezepte/apfelsaft.yaml
Untracked files:
        rezepte/traubensaft.yaml
 
$ git add rezepte/apfelsaft.yaml
$ git status --short
M  rezepte/apfelsaft.yaml
?? rezepte/traubensaft.yaml

modified

Im Working Directory geändert, noch nicht vorgemerkt.

untracked

Neue Datei, die Git noch nicht verwaltet.

M (links)

Vorgemerkt: Diese Änderung geht in den nächsten Commit.

Von SVN zu Git · Tag 1

git status ist der wichtigste Befehl des ersten Tages. Ermutigen Sie die Teilnehmenden, ihn nach jedem Schritt auszuführen.
