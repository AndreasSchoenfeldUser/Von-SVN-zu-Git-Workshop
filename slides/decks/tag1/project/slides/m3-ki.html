Modul 03 · Arbeiten und festhalten

Mit KI vertiefen

VERSTEHEN

Ich komme von SVN, wo ein Commit sofort auf dem Server landet. Erkläre, warum ein Git-Commit lokal bleibt, welche Freiheiten mir das im Arbeitsalltag gibt und welches Risiko besteht, solange ich nicht pushe.

ÜBEN

Gib mir eine Übung für die Kommandozeile: Repository mit git init -b main anlegen, drei Dateien ändern, mit git diff prüfen und in zwei getrennten Commits festhalten. Prüfe danach meine Ausgabe von git log.

ÜBERTRAGEN

Welche Git-Einstellungen sollte ich als Erstes vornehmen, wenn ich unter Windows in einem Java-Projekt arbeite? Begründe jede kurz, gehe auf Zeilenenden ein, lass Werte weg, die Git selbst ermittelt, und verwende Platzhalter für Name und E-Mail.

Für Claude und ChatGPT. Antworten mit den Referenzen abgleichen, keinen vertraulichen Code eingeben.

Von SVN zu Git · Tag 1

Beim dritten Prompt sollte die KI auf Zeilenenden eingehen (core.autocrlf oder .gitattributes). Im Test empfahl Claude ohne den Zusatz, core.ignorecase global zu setzen; diesen Wert ermittelt Git beim Anlegen selbst, er sollte nicht verändert werden.
