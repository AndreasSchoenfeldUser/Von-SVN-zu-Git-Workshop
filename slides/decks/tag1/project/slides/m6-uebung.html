Modul 06 · Ein Branch pro Aufgabe

Zwei Aufgaben, ein Repository

  1. Legen Sie den Branch rezept/orangensaft an, ergänzen Sie das Rezept und committen Sie.
  2. Wechseln Sie zu main und legen Sie den Branch linie2/temperatur an. Ändern Sie dort config/anlage.yaml und committen Sie.
  3. Führen Sie beide Branches nacheinander in main zusammen.
  4. Welche Art von Merge entsteht jeweils? Begründen Sie es anhand der grafischen Historie.

ZEIT

35 Minuten

ARBEITSFORM

Einzelarbeit

ERGEBNIS

main enthält beide Aufgaben; Sie können erklären, warum einmal Fast-Forward und einmal ein Merge-Commit entstand.

Von SVN zu Git · Tag 1

Die beiden Branches ändern bewusst unterschiedliche Dateien, damit hier noch keine Konflikte entstehen.
