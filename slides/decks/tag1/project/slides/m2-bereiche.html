Modul 02 · Das Git-Modell

Drei Bereiche auf Ihrem Rechner

Working Directory

Die Dateien, an denen Sie arbeiten. Hier ändern Sie wie gewohnt.

git add

Staging Area

Die Vormerkung: Was soll in den nächsten Commit?

git commit

Lokales Repository

Die vollständige Historie aller festgehaltenen Stände.

Die Staging Area ist neu für SVN-Anwender. Sie erlaubt, aus vielen Änderungen gezielt einen sauberen Arbeitsschritt zusammenzustellen.

Von SVN zu Git · Tag 1

Betonen Sie die Staging Area als Werkzeug, nicht als Hürde: Sie ist die Packstation, an der ein Commit zusammengestellt wird.
