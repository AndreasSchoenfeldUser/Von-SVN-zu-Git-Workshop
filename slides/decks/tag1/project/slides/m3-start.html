Ein Repository für die Abfüllanlage

# Einmalig: Wer sind Sie?
$ git config --global user.name "Erika Muster"
$ git config --global user.email erika@example.com
 
$ cd abfuellanlage
$ git init
$ git add config/anlage.yaml rezepte/
$ git commit -m "Grundkonfiguration anlegen"
[main (root-commit) 3f2a9c1] Grundkonfiguration anlegen
$ git log --oneline
3f2a9c1 Grundkonfiguration anlegen

git config

Name und E-Mail stehen in jedem Commit. Einmal pro Rechner einrichten.

git init

Macht das Verzeichnis zum Repository. Die Historie liegt im Ordner .git.

git log

Liest die Historie, ganz ohne Server.
