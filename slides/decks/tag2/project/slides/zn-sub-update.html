Eine neue Version des Submodules übernehmen

Eine neue Version der Bibliothek zu übernehmen, ist ein bewusster Schritt mit eigenem Commit.

$ cd externals/portal-common
$ git checkout main # falls nötig
$ git pull
$ cd -
$ git status
  modified:   externals/portal-common (new commits)
$ git add externals/portal-common
$ git commit -m "portal-common auf neuen Stand bringen"
$ git push

Im Submodule

Ein eigenes Repository: neuen Stand der Bibliothek abholen.

cd -

Zurück in das Reiseportal.

git add, commit

Hält fest, welchen Commit der Bibliothek das Reiseportal ab jetzt verwendet.

Von SVN zu Git · Tag 2

git add . funktioniert ebenso, nimmt aber alle anderen Änderungen mit. Der Commit macht die neue Version für das ganze Team verbindlich, so wie jede andere Änderung über einen Merge Request.
