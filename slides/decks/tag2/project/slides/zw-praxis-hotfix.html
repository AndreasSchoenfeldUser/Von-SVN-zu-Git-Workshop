Ein Hotfix für die Produktion

$ git switch main && git pull
$ git switch -c hotfix/1.1.1-wechselzeit
$ git commit -am "Wechselzeit Orangensaft korrigieren"
$ git push -u origin hotfix/1.1.1-wechselzeit
# Merge Request: hotfix/… → main
 
$ git switch main && git pull
$ git tag -a v1.1.1 -m "Hotfix 1.1.1"
$ git push origin v1.1.1
# Merge Request: hotfix/… → develop

Von main

Der Fix basiert auf dem Stand, der in Produktion läuft.

v1.1.1

Die Hotfix-Version wird auf main getaggt.

Nach develop

Damit der Fehler im nächsten Release nicht zurückkehrt.

Von SVN zu Git · Tag 2

Wenn gerade ein Release-Branch offen ist, geht der Hotfix statt nach develop in den Release-Branch. Von dort gelangt er mit dem Release nach develop.
