Modul 08 · Rückblick

Mit KI vertiefen

VERSTEHEN

Fasse die Git-Grundlagen zusammen, die man vor der Teamarbeit sicher beherrschen sollte: drei Bereiche, Commit, Branch und Rückgängigmachen. Je ein kurzer Absatz, ohne Fachjargon.

ÜBEN

Zeige mir die Ausgabe von git log --oneline --graph eines kleinen Repositories und stelle mir Fragen dazu: Welche Branches gibt es, wo wurde gemergt, worauf zeigt HEAD?

ÜBERTRAGEN

Erstelle mir eine einseitige Übersicht für typische Pannen: falsche Datei vorgemerkt, Commit Message vertippt, auf dem falschen Branch gearbeitet, Änderungen versehentlich verworfen.

Für Claude und ChatGPT. Antworten mit den Referenzen abgleichen, keinen vertraulichen Code eingeben.
