Lokales Repository

Ihre vollständige Kopie. Hier entstehen Commits und Branches.

Remote in GitLab

Die gemeinsame Kopie des Teams, üblicherweise origin genannt.

Beide Kopien sind gleichwertig. Das Remote ist nur die Stelle, auf die sich das Team geeinigt hat.

Von SVN zu Git · Tag 2

Technisch gibt es keinen Server im Sinne von SVN. GitLab hält eine weitere Kopie, die das Team als gemeinsamen Treffpunkt nutzt.
