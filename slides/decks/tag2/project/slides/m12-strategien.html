Modul 12 · Den Teamablauf vereinbaren

Zwei bewährte Abläufe

FEATURE-BRANCHES

GitLab Flow

  • Ein Branch pro Aufgabe, Merge Request in main
  • main ist jederzeit lieferbar
  • Bei Bedarf Branches für Umgebungen oder Releases
  • Guter Einstieg für SVN-Teams

KURZE BRANCHES

Trunk-based Development

  • Branches leben nur Stunden
  • Mehrmals täglich in main integrieren
  • Setzt automatisierte Tests voraus
  • Unfertiges hinter Feature Toggles

Von SVN zu Git · Tag 2

Für Teams, die aus SVN kommen, ist GitLab Flow meist der natürliche Einstieg. Trunk-based Development ist ein lohnendes Ziel, sobald Tests und Pipeline stabil laufen.
