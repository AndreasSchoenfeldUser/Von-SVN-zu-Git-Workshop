Modul 09 · Integrieren

Mit KI vertiefen

VERSTEHEN

Erkläre, wann Git einen Merge-Konflikt meldet und wann es automatisch zusammenführt, auch bei benachbarten Zeilen. Zeige an einer YAML-Datei die Basisversion und beide Fassungen, einmal ohne und einmal mit Konflikt, und erkläre die Konfliktmarkierungen.

ÜBEN

Erzeuge eine application.yml für Spring Boot mit drei Konflikten aus einem einzigen Merge, so wie Git sie tatsächlich darstellt, mit steigender Schwierigkeit. Ich schreibe die aufgelöste Fassung, du prüfst sie und erklärst Fehler.

ÜBERTRAGEN

Wie können wir Merge-Konflikte in unserem GitLab-Team seltener machen? Nenne konkrete Maßnahmen zu Branch-Dauer, Dateistruktur und Formatierung für Java-Code mit Maven und Dateien wie application.yml. Verwende GitLab-Begriffe.

Für Claude und ChatGPT. Antworten mit den Referenzen abgleichen, keinen vertraulichen Code eingeben.

Der Übungs-Prompt setzt die Übung dieses Moduls fort. Hartnäckiger KI-Fehler in allen Testläufen: Änderungen in direkt benachbarten Zeilen würden automatisch zusammengeführt. Richtig: Git meldet dann einen Konflikt; erst eine unveränderte Zeile dazwischen erlaubt den automatischen Merge.
