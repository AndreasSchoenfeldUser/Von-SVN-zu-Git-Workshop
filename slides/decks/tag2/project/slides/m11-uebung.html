Modul 11 · Gemeinsam prüfen

Review im Team

  1. Öffnen Sie für Ihren Branch einen Merge Request mit einer Beschreibung, die das Warum erklärt.
  2. Prüfen Sie den Merge Request eines Teamkollegen und hinterlassen Sie mindestens zwei Kommentare.
  3. Setzen Sie die Anmerkungen zu Ihrem Merge Request um.
  4. Geben Sie frei und führen Sie den Merge durch.
  5. Versuchen Sie, direkt auf main zu pushen. Was passiert?

ZEIT

30 Minuten

ARBEITSFORM

Teams mit 3 bis 4 Personen

ERGEBNIS

Mindestens zwei geprüfte und gemergte Merge Requests je Team.

Von SVN zu Git · Tag 2

main ist in den Team-Repositories bereits geschützt. Der abgelehnte Push in Schritt 5 ist beabsichtigt.
