Modul 12 · Den Teamablauf vereinbaren

Den eigenen Branch aktualisieren

$ git switch rezept/multivitamin
$ git fetch
$ git rebase origin/main
Successfully rebased and updated refs/heads/rezept/…
$ git push --force-with-lease
 
# Alternativ mit Merge:
$ git merge origin/main
$ git push

git rebase

Setzt die eigenen Commits auf den aktuellen Stand von main.

--force-with-lease

Überschreibt den eigenen Branch nur, wenn niemand sonst dort gearbeitet hat.

Teamregel

Einmal festlegen, welcher Weg gilt, und dabei bleiben.

Von SVN zu Git · Tag 2

Niemals --force ohne with-lease. Und niemals auf main oder anderen gemeinsam genutzten Branches.
