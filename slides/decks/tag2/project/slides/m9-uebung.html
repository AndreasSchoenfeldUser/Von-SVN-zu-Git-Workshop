Modul 09 · Integrieren

Konflikte gezielt herbeiführen

  1. Legen Sie zwei Branches an und ändern Sie in beiden dieselbe Zeile in config/anlage.yaml.
  2. Führen Sie die Branches zusammen und lösen Sie den Konflikt.
  3. Wiederholen Sie das mit einem Rezept, ändern Sie diesmal aber benachbarte Zeilen. Was passiert?
  4. Starten Sie einen weiteren Merge und brechen Sie ihn bewusst ab.

ZEIT

30 Minuten

ARBEITSFORM

Partnerarbeit

ERGEBNIS

Zwei gelöste Konflikte und ein abgebrochener Merge in der Historie.

Von SVN zu Git · Tag 2

Benachbarte Zeilen führen in der Regel ebenfalls zu einem Konflikt, weil Git Änderungen abschnittsweise vergleicht. Gute Gelegenheit, über kleine, fokussierte Commits zu sprechen.
