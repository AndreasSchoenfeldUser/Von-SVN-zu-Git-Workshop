Zusatzmodul · Nachbereitung des Umzugs

Das migrierte Reiseportal aufräumen

  1. Verschaffen Sie sich mit git lfs migrate info einen Überblick und wählen Sie die Dateitypen für Git LFS aus.
  2. Verschieben Sie diese Dateitypen nach Git LFS und prüfen Sie das Ergebnis mit git lfs ls-files.
  3. Binden Sie die Bibliothek portal-common als Submodule ein und übernehmen Sie anschließend eine neue Version.
  4. Trennen Sie das Verzeichnis hotel-import als eigenes Repository ab und entfernen Sie es aus dem Reiseportal.
  5. Teilen Sie beide Repositories in der GitLab-Gruppe Ihres Teams.

ZEIT

35 Minuten

ARBEITSFORM

Teams mit 3 bis 4 Personen

ERGEBNIS

Ein schlankes Reiseportal mit Git LFS und Submodule sowie ein eigenes Repository hotel-import.

Von SVN zu Git · Tag 2

Grundlage ist das in Modul 14 migrierte Repository. portal-common liegt bereits in der GitLab-Gruppe jedes Teams. Für die neue Version in Schritt 3 legt die Trainerin oder der Trainer während der Übung einen Commit in portal-common an.
